# План развития

## v0.1 — каркас (готово)

- [x] Окна в слое `WorkerW`, несколько мониторов, per-monitor DPI.
- [x] GIF через WIC с задержками кадров.
- [x] Видео через Media Foundation с зацикливанием.
- [x] Режимы `fit` / `fill` / `stretch`.
- [x] Трей, настройки, автозапуск, журнал.
- [x] Пауза при блокировке и в полноэкранных приложениях.
- [x] Перезапуск Explorer, смена мониторов, потеря D3D-устройства.

## v0.2 — качество видео

- [ ] Аппаратный декод: `IMFSourceReader` с `MF_SOURCE_READER_D3D_MANAGER`,
      кадр сразу в `ID3D11Texture2D` (DXVA), без копирования через CPU.
- [ ] Отдельный поток декодирования + двойная буферизация.
- [ ] Учёт `MF_MT_VIDEO_ROTATION` (видео с телефонов).
- [ ] Аудио: опционально, с выбором устройства и приглушением в паузе.

## v0.3 — контент и UX

- [ ] WebView2-обои (HTML/JS/WebGL) через `CoreWebView2CompositionController`.
- [ ] Библиотека обоев в трее, превью, горячая смена.
- [ ] Настройки через GUI (WinUI 3 или простой Win32-диалог).
- [ ] Плейлист: несколько файлов со сменой по таймеру.
- [ ] Разные обои на разные мониторы.

## v0.4 — надёжность и поставка

- [ ] Автотесты: юнит-тесты парсинга настроек и таймингов GIF.
- [ ] CI-артефакты для MSVC и MinGW (см. `.github/workflows/build.yml`).
- [ ] Инсталлятор (Inno Setup / MSIX), подпись бинарника.
- [ ] Телеметрия не нужна; вместо неё — «Диагностика» в трее (копирует
      журнал и сведения о системе в буфер обмена).

## Идеи на будущее

- Шейдерные обои (фракталы, плазма) без файлов.
- Реакция на музыку через WASAPI loopback.
- Автопауза при работе от батареи с настраиваемым порогом.
- Поддержка HDR-вывода (`DXGI_FORMAT_R10G10B10A2_UNORM` + tone mapping).
