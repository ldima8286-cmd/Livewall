# Ручной тест-план (Windows)

Автотестов в проекте пока нет: почти всё поведение завязано на Explorer, DWM и
конкретную сборку Windows, поэтому проверять нужно на живой системе.

## 0. Подготовка

- [ ] `%LOCALAPPDATA%\LiveWall\livewall.log` создаётся при старте.
- [ ] В журнале есть строка `renderer initialized`, `media opened`, `desktop host started`.
- [ ] Значок появился в трее, подсказка содержит имя файла.

## 1. Базовый запуск

- [ ] `livewall.exe file.gif` — GIF виден под иконками, анимация идёт.
- [ ] `livewall.exe file.mp4` — видео играет без звука и зацикливается.
- [ ] `livewall.exe file.png` — статичная картинка, CPU в простое ~0%.
- [ ] Иконки рабочего стола кликаются, выделяются и перетаскиваются.
- [ ] Правый клик по рабочему столу открывает штатное меню, а не меню LiveWall.
- [ ] Окно не появляется в Alt+Tab и на панели задач.

## 2. Масштабирование

- [ ] `fit`: на мониторе 16:9 GIF 1:1 — по бокам фон, пропорции не искажены.
- [ ] `fill`: картинка заполняет экран, лишнее обрезано, полос нет.
- [ ] `stretch`: заполняет экран с искажением.
- [ ] Смена режима из трея применяется сразу.

## 3. Мониторы и DPI

- [ ] Два монитора: обои на обоих, картинка не растянута на виртуальный экран.
- [ ] Монитор с масштабом 150%: изображение не мыльное и не смещено.
- [ ] Отключение/включение второго монитора на ходу: окна пересоздаются.
- [ ] Смена разрешения: обои подстраиваются, артефактов нет.

## 4. Жизненный цикл

- [ ] Перезапуск Explorer (`taskkill /f /im explorer.exe` + запуск) — обои
      возвращаются в течение ~2 секунд, трей тоже.
- [ ] Блокировка сеанса (Win+L) — рендер останавливается (в журнале
      `rendering paused`), после разблокировки продолжается.
- [ ] Запуск игры в полноэкранном режиме — пауза; Alt+Tab — возобновление.
- [ ] Сон/гибернация — после пробуждения видео продолжает играть.
- [ ] Выход из трея — окна уничтожены, штатные обои вернулись.

## 5. Медиа

- [ ] GIF с прозрачностью: фон чёрный, артефактов композиции нет.
- [ ] GIF с задержками 20/100 мс: темп совпадает с браузером.
- [ ] Видео 24 fps: не ускоряется, звук не играет.
- [ ] Видео с вращением (снятое на телефон): **ожидаемо** может быть
      повёрнуто неверно, см. ROADMAP.
- [ ] Файл без декодера (например, HEVC без расширения): понятная ошибка,
      приложение не падает.
- [ ] Очень большое видео (4K): воспроизведение без рывков, CPU/GPU в норме.

## 6. Настройки

- [ ] Выбранный файл и режим сохраняются после перезапуска.
- [ ] «Запускать при входе» создаёт/удаляет значение в
      `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- [ ] Повторный запуск с другим файлом переключает обои у работающего
      экземпляра.
- [ ] Удаление файла обоев и перезапуск: ошибка в журнале, трей жив.

## 7. Совместимость

Проверить на актуальных сборках: Windows 10 22H2, Windows 11 23H2, 24H2, 25H2.
Для каждой сборки отдельно отметить, какой из стратегий поиска слоя
сработал (см. строку `desktop host started` и предупреждение про Progman).
